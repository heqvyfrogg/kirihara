# 桐原書店「きりはらの森の学校」自動テスト解答ツール (Kirihara Auto Tester)

桐原書店の生徒用学習プラットフォーム「きりはらの森の学校（フォレストテスト 生徒用 / Moritest Students）」におけるテストの自動受験・解答提出を行う Python CLI ツールです。

---

## 🌟 主な特徴

- **API直接連携 & 自動ログイン**: アカウント名とパスワードを設定するだけで、Cookie不要で完全自動認証。
- **Gemini APIバッチ解答**: テスト全問（20問等）を**1回のリクエスト**で一括解答し、API無料枠・トークン消費を最小化（約95%削減）。
- **ローカルキャッシュ機能**: 一度解いた問題は `kirihara_cache.json` に自動保存され、次回以降は **0トークン（API消費ゼロ）** で即答。
- **多彩な出題形式に対応**:
  - 英語：日英・英日 4択問題、下線部和訳・空所補充、語順整序（並び替え）、リスニング音声問題
  - 古文：古文単語の意味選択、現代語訳
- **安全・スケジュール管理機能**:
  - `info`: 配信テストの実施期間（JST）、制限時間、大問構成を確認。
  - `--dry-run`: サーバーに送信せず、AIが導出した解答と完成英文をプレビュー確認。
  - `--wait`: 開始前のテストに対し、開始時刻まで待機して自動受験。
  - `--human-like`: 自然な思考時間を模倣するランダムディレイ機能。
  - `--target-accuracy 90`: 意図的に数問間違えて90%前後のスコアに調整可能。

## 🚀 セットアップ

### 1. 必要要件
- Python 3.10 以上

### 2. 依存パッケージのインストール
```bash
pip install -r requirements.txt
```

### 3. 環境設定 (`.env`)
`.env.example` をコピーして `.env` を作成し、アカウント情報とGemini APIキーを設定します。

```bash
cp .env.example .env
```

```ini
# 桐原書店 生徒用アカウント情報（Cookie不要で自動ログイン）
KIRIHARA_ACCOUNT_NAME=your_student_account_id
KIRIHARA_PASSWORD=your_student_password

# Google AI Studio で取得した Gemini API キー (無料枠あり)
GEMINI_API_KEY=your_gemini_api_key_here
```

### 5. 本番自動解答＆提出 (`run`)

```bash

python main.py run 94506 --human-like

# 意図的に90%前後の正答率に調整して提出
python main.py run 94506 --human-like --target-accuracy 90

```
