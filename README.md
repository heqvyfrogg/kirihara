# kirihara-auto-tester

桐原書店の学習プラットフォーム「きりはらの森の学校（フォレストテスト 生徒用）」向けの自動テスト解答・提出CLIツールです。

## 主な機能

- **認証**: アカウント名とパスワードによる自動認証（セッション維持）。
- **バッチ推論**: テスト全問を1回のリクエストにまとめて解答を生成し、APIの呼び出し回数およびトークン消費を抑制。
- **キャッシュ**: 一度解答した問題はローカル（`kirihara_cache.json`）に保存し、再受験時は外部通信なしで即時解答。
- **各種問題形式に対応**:
  - 英語: 選択問題（4択）、下線部和訳・空所補充、語順整序（並び替え）、リスニング問題
  - 古文: 古文単語の意味選択、現代語訳
- **制御オプション**:
  - `info`: 配信テストの実施期間、制限時間、構成の確認。
  - `--dry-run`: サーバーへの提出を行わず、推論された解答内容をプレビュー。
  - `--wait`: 開始前テストの開始時刻まで待機して自動実行。
  - `--human-like`: 解答間にランダムなディレイを挿入。
  - `--target-accuracy`: 目標正答率に応じた解答調整。

## セットアップ

### 必要要件
- Python 3.10 以上

### インストール
```bash
pip install -r requirements.txt
```

### 設定
`.env.example` をコピーして `.env` を作成し、認証情報とGemini APIキーを設定してください。

```bash
cp .env.example .env
```

```ini
KIRIHARA_ACCOUNT_NAME=your_student_account_id
KIRIHARA_PASSWORD=your_student_password
GEMINI_API_KEY=your_gemini_api_key
GEMINI_MODEL=gemini-flash-latest  # 任意 (デフォルト: gemini-flash-latest)
```

```bash
# 基本一覧（配信日時順）

python main.py list --sort score --reverse

# 開始前（未受験）のテストのみに絞り込む
python main.py list --filter-status upcoming

# 指定年度、ID順に並べる
python main.py list --year 2026 --sort id
```

### 5. 解答実行・提出
```bash
# 人間らしい思考時間を模倣して提出（問題形式・問題数に応じて1問あたり約4～12秒を動的シミュレート）
python main.py run 94506 --human-like

# 思考速度倍率を指定（2.0 で2倍速、0.5 でじっくり）
python main.py run 94506 --human-like --speed 2.0

# 待機秒数を直接指定（例: 60秒待機）
python main.py run 94506 --delay-sec 60

# 即時提出（待機なし）
python main.py run 94506 --instant

# 正答率を約80%に調整して提出（意図的に数問間違える）
python main.py run 94506 --human-like --target-accuracy 80

# 開始時刻まで待機して自動実行
python main.py run 94508 --wait --human-like
```
